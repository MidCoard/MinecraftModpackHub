打开产线规划器↗如何使用 ↓

直接读取导出的 JSON，无需运行 Java，也不上传整合包。

FactoryCanvas产线示意
物料与机器连接 → 求解 → 验证

导入真实配方

选择导出的整合包 JSON，或使用站点提供的配方数据。

连接与求解

设置供给、机器和目标产量，检查物料平衡、供电与设备需求。

验证实际执行

在实时仿真中观察物料流动与加工进度，保存方案并继续调整。

在浏览器中开始

你的整合包，留在本机。

规划器仅在你选择后读取 JSON，计算和方案保存在浏览器中，不上传游戏文件。

选择数据，开始规划

打开规划器，导入整合包 JSON，再选择配方与目标：

JSON → 配方与物料 → 求解与仿真

保存方案版本，并定期导出方案备份。清除站点数据会删除浏览器中的副本。

当前支持范围

离线元信息读取支持 Forge、NeoForge 与 Fabric。游戏内采集适配目标为 Minecraft 1.20.1 / Forge 47.4.16，目前已编译验证，尚未完成发行前的游戏内验收；NeoForge 与 Fabric 运行时采集尚未实现。静态导入不等同于游戏最终配方。
